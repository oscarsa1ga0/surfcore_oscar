# 鱼姬之家记忆同步

网页主人私聊取代 QQ 主聊后，日记回顾直接读取当前角色当天的网页历史。只有 QQ 作为主聊载体时才请求 QQ 历史及近期消息文件。网页和日记的记忆提示词过滤配置中近期窗口里的 QQ 条目，旧记忆留在角色卡和档案里。QQ 主人私聊可以召回网页记忆，QQ 群聊和其他私聊继续隔离。

## 链路与根因

- 网页消息原本进入本地 SQLite 和角色记忆收件箱。日记回顾只读取 QQ 历史，长期节选也固定读 QQ 预渲染文件。现在从 SQLite 按角色和日期读私聊，包括以前已经写入的网页文字，给网页聊天素材留定额以便当天 B 站经历也能入选。日记工具自动标记当前网页回合的来源。语音转写保存在同一个库的独立表里，用于回顾和记忆。图片记录附件事实，图意由鱼姬看图后自己暂存。
- B 站调度原本从 QQ 群近况及 QQ 最近收尾取材。网页主聊时暂停这两个入口。网页自然收尾可以写一份单独的公开安全近况，只在角色相同、七日内且仍是最新收尾时注入 B 站。私事收尾可以留空。没有对旧网页记录做摘要回填。B 站看不到网页原始聊天或私聊记忆卡。
- B 站简报和索引原本由 QQ 桥接进程定时刷新。网页主聊时宿主接管同一角色索引的刷新，手动刷新走同一入口。网页与 QQ 沿用同一 B 站简报和关键词召回开关。叙事和向量注入按统一模式二选一。
- 重要主人记忆超过上限后，旧版会在 B 站记录刚写入时删掉它，去重标记却已持久化。现在给 B 站经历保留约八分之一上限的空间。已有受保护记录保留。在确认已有记录挤满卡、历史上摄取过 B 站经历且近期公开索引可用的角色上，自动补回一批近期公开条目。后续手动忘记的 B 站条目会记录标识，避免重入。
- 网页文字、图片附言和现场合成语音都执行日记原文授权检查，拒绝会返回错误码和授权步骤。旧语音库文件沿用正常发送流程。B 站网页近况禁用私人日记的摘录授权例外。

## 取舍与影响

沿用 SQLite、角色目录及现有主聊载体，切换投递即可切换近期来源。复制网页历史到 QQ 状态虽然能兼容已有回顾入口，却会混淆来源并增加重复数据和跨平台读取范围。共享整份网页收尾能带上更多细节，B 站会话也可能在同一轮执行公开互动，因此只接续鱼姬单独写的安全摘要。

改动涉及 DSH 宿主、B 站调度、日记调度和 QQ 的向量检索及刷新职责。无需手动迁移数据库。首次启动会为新写入的语音建立转写表，旧网页文字可直接用于定时回顾。保留所有旧 QQ 数据和已有的网页历史。回退可反向应用归档补丁并重开 DSH，SQLite 的新增表会被旧版忽略，已补回的记忆继续按旧版本规则参与整理。

## 验证与发布交接

- 用临时角色和 SQLite 验证网页历史日期与角色隔离，保留语音转写和 B 站经历，摘要失效与私人日记拦截，及记忆卡满载后的 B 站补回。
- 应用代码后重开 DSH。QQ 若仍运行，可重启桥接以采用新的刷新职责。保留网页为主聊即可。
- 真实环境验收可在网页聊一个适合公开的普通话题并让对话自然收尾，随后观察 B 站上线提示能否接续。下一次日记回顾应拿到网页摘要素材及当天 B 站经历。新补语音要在开启且成功转写时才会形成可检索的文字记录。
- 本批次仅在 macOS 安装线基线提交代码及案例。交接时带上记忆同步补丁、专项和审计结果；正式运行需在安装目录应用后验证。
