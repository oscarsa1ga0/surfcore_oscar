# DSH 概览与安装文档同步四个入口

旧概览仍以 QQ 和 B站为主，桥接进程启动后也容易被理解为 QQ 已登录。现在「概览」显示微信私聊、QQ、B站、桌宠的状态，点任意入口可进入对应设置。标题下方显示当前角色。QQ 以 OneBot 连接状态判断可用，微信区分待绑定、暂停、静默和接收，B站分别显示登录配置和生物钟状态，桌宠区分待安装、已装和运行。

概览复用 SurfCore 已有的运行时状态，只返回微信状态摘要。扫码、接收开关和回复规则仍由微信页及 SurfCore 的微信服务管理。重新回到「概览」会刷新状态。macOS 的 QQ 页直接显示 OneBot 配置表单。

中文 README 优先展示 macOS 安装和四个入口的启用步骤，英文 README 与安装手册提供相应入口。代码回退时可恢复本次提交涉及的设置页和文档，渠道状态、账号和角色数据沿用原目录。
