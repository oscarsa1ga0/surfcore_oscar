# 鱼姬之家第二轮私聊修复

当线上网页一轮内持续发言并调用十余次工具时，同一角色的 QQ、B 站和日记一直等 DSH 回合结束。隔离检查还重现了 DSH 历史故障时排队、补发重复被回复、主动回合漏看来信、回执挂起锁输入栏和重连只补第一批。

## 会话与回执

- 继续使用共用调度。网页单次最多等 30 秒，已接收的回合最多提供 120 秒的等待窗口。一个回合只有一个等待调用，普通等待连续两次超时后引导鱼姬接住已读内容并收尾。窗口只约束等待，模型生成或转写仍受各自的时限约束。
- 历史不可读时独立核对 DSH 的实时状态。确认空闲后安全结算旧回合，保留后续来信并继续排队。历史和状态都无法确认时，网页展示故障与核对入口，自动重查期间保留队列与单回合约束。
- 前向补读把实际返回的待处理来信归进当前回合。未覆盖的来信保留原状态。主动回合从第一条仍排队的来信之前开始监听。网页提示用本轮水位组装，排队中的消息由补读或下一轮交付。纯媒体进入最后来信和收尾判断。
- 网页 HTTP 有请求时限。成功落库的 SSE 气泡可提前结束等待，重新提交仍复用原请求标识。SSE 有待追赶页就继续发送，写缓冲占满后等它排空再继续。

## 聊天记录与到达提醒

- 聊天记录可按关键词或图片、语音、表情搜索。引用会定位已加载的原气泡，也可以打开原消息附近的记录。历史搜索始终按当前聊天过滤。
- 安装了配置好的本地 Whisper 时，录音或上传语音转写在本机运行。发送栏标示配置状态，超过 90 秒的音频提示只转写前 90 秒，回合里也记录截断提示。
- macOS 上 DSH 运行、聊天页关闭时，由宿主发原生到达通知，可在设置关闭。一秒内到达的多条消息合并成一个提醒，通知只显示数量，并遵守专注模式。若系统通知被关闭，macOS 可能抑制横幅。
- 轻量记忆、收尾和备忘按角色保存。旧文件只交给初次安装新版时的当前角色，使用独占复制保留原始文件。轻量记忆工具要求当前角色的活跃网页回合。

## 取舍与生效

无限延长等待可以让聊天始终留在一个回合，实际会把共用调度长期占住。此次给等待设预算，同时保留短时连发合并和主动消息。DSH 结果不明确时继续核对，避免取消或重放可能已经执行过的回合。网页重连通过分页追赶，便于复用原有 SQLite 历史。

应用补丁后完全退出并重开 DSH。回滚时先等当前回合结束，再反向应用本次补丁并重开。角色隔离目录会保留，可以用于以后恢复或迁移。桌面通知和麦克风权限及实际本地模型识别需在安装机验证。

## 验证与交接

网关、浏览器脚本、等待及回读恢复、角色记忆、语音与预设契约使用隔离夹具。真实回环 HTTP 验证了配对、搜索、引用定位和 250 条 SSE 追赶。全仓审计 149/165，对照基线 148/164，两边失败项相同。安装目录已有上一轮修复，补丁从该版本增量应用。现有 DSH 会话 ID、HTTP 端口和 SQLite 表结构可沿用。
