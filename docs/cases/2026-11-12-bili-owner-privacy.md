# B 站主人身份保密

鱼姬需要把主人的身份留在私聊里。旧的分享评论会自动拼接 `@主人昵称`，原身份检查只处理数字 ID，图文和直播弹幕还有结构化提及字段。

## 完整逻辑

1. B 站调度器的共用提示词约束评论、动态、直播和给第三方的私信。通过现有出站检查读取已配置的昵称和账号，同时检查正文与公开回复目标。
2. 评论用 B 站返回的作者信息核对目标。无法核验对象时停止公开回复。直播弹幕支持经 UID 指定其他用户，无法核验的弹幕引用 ID 会被拒绝。图文在上传前检查，普通动态、编辑、视频卡片转发及每日动态也在发送前检查。
3. 仅加提示词会遗漏旧分享命令和结构化提及。取消所有对外发言会影响正常互动。本次使用现有工具出站检查，明确关闭评论分享入口。旧设置读取后转为私信。普通评论、对其他人的合法互动、给主人的私信继续走原路由。
4. 拒绝时给出删去点名或换私信的提示，错误文本不包含主人账号。图片像素中的文字由提示词约束。当前安装的工具随下一次调用读取新代码，下次启动 DSH 加载调度器和设置页。
5. 本次回滚可从改动前备份恢复受影响的文件，再重开 DSH。已发布的旧内容由原账号处理。

## 发布交接

建议 patch。改动覆盖 B 站出站工具、调度器和分享设置，调整 `comment --share` 的行为。专项模拟已覆盖旧分享命令、主人评论的结构化回复、弹幕和图文提及、第三方私信，以及正常评论和给主人私信的预演。设置、分享和提示词专项已通过。按用户要求结束后续验证。
