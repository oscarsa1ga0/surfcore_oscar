# 网页端退役 QQ 接入

鱼姬之家和 B 站直接由 SurfCore 宿主管理。配置页提供网页或桌宠主动搭话、共享语音和独立 B 站记忆设置。日记回顾使用当天网页消息及 B 站经历。手动记忆默认归鱼姬之家，记忆设置显示网页和 B 站各自的注入预览。

## 升级

1. 将代码变更应用到本机 DSH 正在加载的 SurfCore 仓库。已有用户首次启动会把主动搭话、语音、B 站记忆开关和身份设置迁到 SurfCore 的统一配置。迁移前自动备份统一配置。
2. 用 DSH 的 Node 运行 `node scripts/setup-dsh.mjs --retire-qq desktop`。如安装在别的 profile，把 `desktop` 换成实际 profile 名。此命令只从该 profile 移除旧 QQ 工具接入，给有改动的 profile 文件留备份。可以重复运行。
3. 完全退出并重开 DSH。概览应有鱼姬之家和 B 站，语音页可以独立运行 Breeze 自检。日记页可以从鱼姬之家和 B 站取材。

## 存量数据与回退

网页聊天、角色、历史 QQ 记录和旧配置留在原有位置。迁移后的网页和桌宠调用新的通用设置。旧 QQ 桥接源码仍在仓库历史和兼容测试里，需要 QQ 时使用旧分支和备份 profile。恢复旧版本的操作需要恢复 profile 的工具清单和代码，并用统一配置的迁移前备份恢复旧开关。

## 验证

- 宿主冒烟在临时环境自动迁移带 Breeze 配置的旧安装，再移走旧 QQ 配置，验证语音自检、B 站开关、网页主聊和口令遮盖。旧管理路由返回 404。
- profile 测试确认两个 QQ MCP 和 QQ 模式入口移除，网页图片工具保留，且二次执行幂等。
- 网页会话、日记回顾、B 站摘要和长期记忆通过各自的离线测试。真实账号的在线收发由安装后验收。
